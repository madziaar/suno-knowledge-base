## First Launch Setup

### 1. Audio Setup (IMPORTANT!)

**File → Preferences → Audio**

**Driver Type:** ASIO (Windows)
- If no ASIO device: Install **ASIO4ALL** (free)
- Download: https://www.asio4all.org/

**Audio Device:** Your audio interface or ASIO4ALL

**Sample Rate:** 48000 Hz (standard for music production)

**Buffer Size:**
- **Recording:** 128-256 samples (low latency)
- **Mixing:** 512-1024 samples (better performance)

### 2. MIDI Setup

**File → Preferences → Link, Tempo & MIDI**

**Control Surface:** None (unless you have MIDI controller)

**Input/Output:** Enable your MIDI keyboard if you have one

### 3. Library Location

**File → Preferences → Library**

**Library Location:** Default is fine
- `C:\Users\[YourName]\Documents\Ableton\`

**Save all packs here** (don't move this folder!)

## Quick Start: Your First Beat

### Step 1: Create New Project

1. File → New Live Set
2. File → Save As → "MAG_Beat_01"
3. Location: `C:\MAG_Beats\MAG_Beat_01\`

### Step 2: Add Drums

**Method 1: Drag & Drop Samples**
1. Open **Browser** (left panel)
2. Navigate: Samples → Drums → Hip Hop
3. Drag kick drum to **Audio Track 1**
4. Drag snare to **Audio Track 2**
5. Drag hi-hat to **Audio Track 3**

**Method 2: Use Drum Rack**
1. Drag **Drum Rack** from Browser → Instruments
2. Drag drum samples into pads
3. Play pads with MIDI keyboard or click

### Step 3: Add 808 Bass

1. Create MIDI track: **Ctrl+Shift+T**
2. Drag **Operator** synth from Browser → Instruments
3. Load preset: **808 Sub Bass**
4. Draw notes in piano roll (Ctrl+Shift+M to open)
5. Draw low notes (C1, F1, G1) for 808 bassline

### Step 4: Add Melody

1. Create MIDI track
2. Drag **Analog** synth from Browser
3. Load preset: **Keys** or **Pad**
4. Draw melody in piano roll

### Step 5: Arrange

1. Switch to **Arrangement View** (Tab key)
2. Record or copy clips from Session View
3. Arrange sections: Intro → Verse → Chorus → Bridge → Outro

### Step 6: Mix

1. Adjust volume faders (left side of tracks)
2. Pan instruments (stereo position)
3. Add effects: Reverb, Delay, EQ

### Step 7: Export

1. File → Export Audio/Video
2. **Rendered Track:** Master
3. **File Type:** WAV
4. **Sample Rate:** 48000 Hz
5. **Bit Depth:** 24
6. **Normalize:** On
7. Click Export

**Your first beat is done!** 🎉

## Performance Optimization

### Speed Up Ableton

**1. Increase Buffer Size**
- Preferences → Audio → Buffer Size: 512 or 1024
- Only lower to 128 when recording live

**2. Freeze Tracks**
- Right-click track → Freeze Track
- Converts MIDI/plugins to audio (saves CPU)

**3. Disable Auto-Save**
- Preferences → File/Folder → Auto Save: Off
- Manually save instead (Ctrl+S)

**4. Use External Plugins Sparingly**
- Ableton's built-in effects are lightweight
- Too many VSTs = lag

**5. Close Unnecessary Apps**
- Close Chrome, Spotify, etc. while producing

## Troubleshooting

### Issue: "Audio crackling/popping"
**Solution:**
- Increase buffer size (512 or 1024)
- Disable power saving mode (Windows settings)
- Update audio drivers

### Issue: "Ableton won't open"
**Solution:**
- Run as Administrator
- Disable antivirus temporarily
- Reinstall (settings are saved)

### Issue: "Plugins not showing up"
**Solution:**
- Preferences → Plug-ins
- Rescan VST folders
- Check plugin format (VST2 vs VST3)

### Issue: "Can't export WAV"
**Solution:**
- Check disk space (need 500MB+ free)
- Export to different location
- Close other audio programs
