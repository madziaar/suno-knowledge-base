# Album Factory Variation: Portuguese Upper Class

## Overview

This variation produces content in refined European Portuguese (Portugal, not Brazil) with sophisticated vocabulary, proper grammar, and an elegant tone. Based on the UK Upper Class variation but adapted for Portuguese aristocratic/upper class language.

**Reference Project:** MAG_Refined_Vol_1 (UK version)

---

## Sound Profile

**Identical to UK Upper Class.** This is smooth, melodic, warm production — NOT Trap/Drill.

### Production Style
| Element | Specification |
|---------|---------------|
| Genre | Reggae Fusion R&B, Smooth R&B |
| BPM Range | 95-110 |
| Reference | Akon "Konvicted" era (2006-2008) |
| Drums | Island percussion, reggae one-drop |
| Bass | Warm, melodic (not 808 trap) |
| Keys | Rhodes, warm synth pads |
| Guitar | Reggae skank, clean electric, acoustic |
| Vocals | Melodic singing, Auto-Tune warmth |

### Vocal Delivery
- Smooth, melodic singing in Portuguese
- Warm Auto-Tune (not robotic)
- Layered harmonies
- Falsetto on emotional peaks
- NO rap flow, NO aggressive delivery

---

## Language Guidelines

### Portuguese Origin: PORTUGAL (European Portuguese)

**NOT Brazilian Portuguese.** Use European Portuguese from Portugal:
- "Tu" not "você" (informal)
- "Estou" not "Tô"
- "Você" for formal address
- Portuguese pronunciation (not Brazilian)

### Vocabulary Transformation

| Common/Street | Portuguese Upper Class |
|---------------|------------------------|
| "Babe", "Gata" | "Querida", "Minha cara" |
| "Fixe", "Massa" | "Esplêndido", "Magnífico" |
| "Tipo..." | "Devo dizer...", "Parece-me que..." |
| "A sério" | "Sem dúvida", "Indubitavelmente" |
| "Vou fazer" | "Irei", "Hei de" |
| "Chegar" | "Fazer a minha entrada" |
| "Casa", "Spot" | "Residência", "Estabelecimento" |
| "Estilo", "Swag" | "Elegância", "Refinamento" |
| "Boa" (attractive) | "Requintada", "Deslumbrante" |
| "Ambiente" | "Atmosfera", "Ambiência" |

### Upper Class Portuguese Expressions

| Function | Portuguese Upper Class |
|----------|------------------------|
| Agreement | "Certamente", "Precisamente", "Absolutamente" |
| Surprise | "Meu Deus", "Céus", "Extraordinário" |
| Appreciation | "Esplêndido", "Maravilhoso", "Encantador" |
| Affection | "Minha querida", "Meu amor", "Adorada" |
| Emphasis | "Bastante", "Deveras", "Excepcionalmente" |
| Dismissal | "Isso não importa", "Não tem qualquer relevância" |

### Sentence Structure

**Avoid:**
```
"Tamos a curtir bué, mano"
"Ela é bué boa, tá-se bem"
"Vamos ao spot, vai ser fixe"
```

**Use:**
```
"Estamos a desfrutar de momentos verdadeiramente esplêndidos"
"Ela é absolutamente requintada, elegância personificada"
"Faremos a nossa entrada no estabelecimento, preparados para celebrar"
```

## Thematic Guidelines

### Core Message (Same as UK Version)

Based on Akon's "Don't Matter":
> **"O amor conquista tudo. Juntos, somos imparáveis."**

### Album Arc (6-track EP)

| Track | Theme | Portuguese Title Direction |
|-------|-------|---------------------------|
| 1 | Arrival/Introduction | "Distinto" / "Refinado" |
| 2 | Romantic Devotion | "Sem Dúvida" / "Inquestionável" |
| 3 | Celebration | "Esplêndido" / "Magnífico" |
| 4 | Intimacy | "Encontro Noturno" / "Noite Encantada" |
| 5 | Reflection/Gratitude | "Abençoado" / "Afortunado" |
| 6 | Future/Closing | "Rumo ao Futuro" / "Sempre em Frente" |

### Lyrical Patterns

Same as UK version:
1. **Verse:** Acknowledge the problem/obstacle
2. **Pre-Chorus:** Dismiss the negativity
3. **Chorus:** Affirm the commitment/love
4. **Bridge:** Deeper declaration

**Emotional Arc:**
```
Problema → Desprezo → Afirmação → Resolução
"Eles dizem..." → "Mas isso não importa..." → "Eu amo-te..." → "Vamos ficar bem..."
```

### Direct Address (Second Person)

Write TO the partner:
```
"Tu és a única que vejo"
"Quando precisares de mim, estarei presente"
"Não deixes que eles te afetem, minha querida"
```

NOT about her in third person:
```
AVOID: "Ela é tão bela, é a minha rainha"
USE: "Tu és tão bela, és a minha rainha"
```

## Agent Adjustments

When using production agents with this variation:

### BeatDoctor
- Use reggae/island percussion palette
- Warm synths, not trap leads
- Melodic bass, not 808s

### HumanTouch
- Keep refined Portuguese vocabulary when humanizing
- Natural pauses, not street filler words
- "Pois", "Certamente" as fillers, not "tipo", "ya"

### VocalCoach
- Melodic ad-libs: "Mmm", "Oh", "Sim" (sung)
- NO aggressive ad-libs (no "UGH", "BOW")
- Falsetto suggestions for hooks

### CultureCheck
- Verify upper class Portuguese vocabulary is natural
- Flag any street slang intrusion
- Ensure European Portuguese (not Brazilian)
- Check for consistent register throughout
