# Decisions Folder

**Project:** MAG Hardcore Drill Vol 1

---

## Purpose

This folder tracks all significant creative, technical, and business decisions made throughout the project lifecycle. Maintaining a decision record ensures accountability, enables learning from past choices, and provides context for future reference.

---

## Primary Document

**Decision Log:** [DECISION_LOG.md](./DECISION_LOG.md)

The decision log is the main document in this folder. All project decisions should be recorded there.

---

## Template Reference

```
/templates/decision-log.md
```

Refer to the template for detailed instructions on logging decisions.

---

## Example Use Cases

### Creative Decisions

- Changing a track's tempo, key, or arrangement
- Selecting final artwork from multiple concepts
- Choosing featured artists or collaborators
- Approving or rejecting mix revisions

### Technical Decisions

- Selecting audio formats for delivery
- Choosing distribution platforms
- Setting mastering specifications
- Resolving technical issues or limitations

### Business Decisions

- Adjusting release dates
- Modifying credit splits
- Changing marketing strategies
- Addressing rights or clearance issues

### Process Decisions

- Workflow changes mid-project
- Team role adjustments
- Priority shifts between tracks
- Resource allocation changes

---

## Best Practices

1. **Log immediately:** Record decisions as they are made, not retroactively
2. **Be specific:** Clearly state what was decided and why
3. **Name names:** Attribute decisions to responsible parties
4. **Date everything:** Use YYYY-MM-DD format for consistency
5. **Review regularly:** Check the log during project meetings
