# Archive Folder

**Project:** MAG Hardcore Drill Vol 1

---

## Purpose

This folder stores previous versions of project files that have been superseded but may need to be referenced or restored in the future. Archiving preserves the creative history and provides recovery options without cluttering active working directories.

---

## What to Archive

- Previous versions of audio exports (stems, mixes, masters)
- Superseded artwork concepts and drafts
- Outdated lyrics or description drafts
- Earlier versions of metadata files
- Any file replaced by a newer version

---

## Naming Convention

Use the following format for archived files:

```
[OriginalFilename]_v[Version]_[YYYYMMDD].[ext]
```

**Examples:**

| Original File | Archived As |
|--------------|-------------|
| Track_03_Mix.wav | Track_03_Mix_v1_20250115.wav |
| cover_artwork.png | cover_artwork_v2_20250118.png |
| lyrics_hook.txt | lyrics_hook_v1_20250110.txt |

**Version numbering:**
- Start at v1 for the first archived version
- Increment sequentially (v1, v2, v3...)
- The date should reflect when the file was archived

---

## Folder Organization

For projects with many archived files, organize by type:

```
07_archive/
  audio/
    Track_03_Mix_v1_20250115.wav
    Track_03_Mix_v2_20250120.wav
  artwork/
    cover_artwork_v1_20250112.png
  lyrics/
    lyrics_hook_v1_20250110.txt
```

---

## When to Archive vs Delete

### Archive When:

- The file represents significant creative work
- You might need to reference or restore the previous version
- The decision to change direction was debatable
- The file documents an important iteration in the creative process

### Delete When:

- The file is clearly a mistake or corrupt
- It contains no usable content
- It is a duplicate with no unique value
- Storage space is a critical concern

**When in doubt, archive.** Storage is cheaper than recreating lost work.

---

## Retention Policy

- Keep archived files for the duration of the project plus 1 year after release
- Review and clean up archives during project retrospectives
- Document any deletions in the decision log
