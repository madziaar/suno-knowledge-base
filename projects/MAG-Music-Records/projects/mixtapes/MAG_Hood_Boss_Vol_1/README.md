## Project Overview

MAG Hood Boss Vol. 1 is a Portuguese-language luxury trap mixtape inspired by Rick Ross's commanding delivery style and "Hood Billionaire" aesthetic. This project features 100% original content in European Portuguese, combining cinematic orchestral production with authentic street narratives, luxury imagery, and boss mentality.

**Key Differentiators:**
- European Portuguese lyrics and cultural references
- Rick Ross-inspired vocal delivery (deep, commanding, boss energy)
- Cinematic production with orchestral elements
- Luxury trap aesthetic meets Portuguese street authenticity
- Original narratives celebrating Lusophone culture and success stories

```

```

### 3. Track Progress
Update `05_metadata/release_tracker.md` as you complete each stage:
- ⬜ Pending → 🔄 In Progress → ✅ Complete

## Style Guidelines

### Vocal Direction
- **Deep commanding baritone** (Rick Ross reference)
- **Measured, confident delivery** (NOT rushed or aggressive)
- **Boss talk energy** with motivational themes
- **Clear European Portuguese pronunciation**

### Production Style
- **Cinematic orchestral elements** (strings, brass, piano)
- **Heavy 808s and luxury trap drums**
- **Wide stereo field with polished mix**
- **Radio-ready quality**

### Lyrical Themes
- Hood to riches narrative
- Luxury lifestyle (cars, watches, success)
- Boss mentality and leadership
- Portuguese/Lusophone cultural pride
- Street credibility meets sophistication

## File Naming Conventions

### Track Files
```
track_[NN]_[short_name]_[type].[ext]

Examples:
- track_01_boss_intro_prompt.txt
- track_01_boss_intro_lyrics.txt
- track_01_boss_intro_description.txt
```

### Audio Exports (local only)
```
track_[NN]_[short_name]_v[N].[ext]

Examples:
- track_01_boss_intro_v1.mp3
- track_01_boss_intro_final.wav
```

## Important Notes

### What NOT to Commit
- Audio files (.mp3, .wav, .flac) → Store locally in `03_audio_exports/`
- Large video files
- Personal credentials or API keys

### What TO Commit
- Suno prompts and lyrics
- Track descriptions and metadata
- Artwork (PNG/JPG only, optimized)
- Documentation and decision logs
- Credits and release tracking
