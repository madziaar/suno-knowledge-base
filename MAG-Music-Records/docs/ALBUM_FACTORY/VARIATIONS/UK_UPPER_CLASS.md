# Album Factory Variation: UK Upper Class English

## Overview

This variation produces content in refined UK English with sophisticated vocabulary, proper grammar, and an elegant tone. Suitable for romantic R&B, smooth reggae fusion, and sophisticated pop.

---

## Sound Profile

**NOT Trap/Drill.** This is smooth, melodic, warm production.

### Production Style
| Element | Specification |
|---------|---------------|
| Genre | Reggae Fusion R&B, Smooth R&B |
| BPM Range | 95-110 |
| Reference | Akon "Konvicted" era (2006-2008) |
| Drums | Island percussion, reggae one-drop |
| Bass | Warm, melodic (not 808 trap) |
| Keys | Rhodes, warm synth pads |
| Guitar | Reggae skank, clean electric, acoustic |
| Vocals | Melodic singing, Auto-Tune warmth |

### Vocal Delivery
- Smooth, melodic singing
- Warm Auto-Tune (not robotic)
- Layered harmonies
- Falsetto on emotional peaks
- NO rap flow, NO aggressive delivery

---

## Language Guidelines

### Vocabulary Transformation

| Common/Street | UK Upper Class |
|---------------|----------------|
| "Babe", "Shawty" | "Darling", "My dear" |
| "That's lit/fire" | "Splendid", "Magnificent" |
| "I be like..." | "One finds...", "I must say..." |
| "No cap", "For real" | "Without question", "Indeed" |
| "Imma", "Finna" | "I shall", "One must" |
| "Pull up" | "Arrive" |
| "Crib", "Spot" | "Residence", "Establishment" |
| "Drip", "Swag" | "Elegance", "Refinement" |
| "Bad" (attractive) | "Exquisite", "Stunning" |
| "Vibes" | "Atmosphere", "Ambience" |

### Sentence Structure

**Avoid:**
```
"We out here getting money every day"
"She bad, she got that drip for real"
"Pull up to the club, we finna turn up"
```

**Use:**
```
"Fortune continues to favour us, without question"
"She's absolutely exquisite, elegance personified"
"We shall arrive at the establishment, prepared for celebration"
```

### Expressions

| Function | Upper Class Expression |
|----------|------------------------|
| Agreement | "Indeed", "Quite so", "Absolutely" |
| Surprise | "My word", "Good heavens", "How extraordinary" |
| Appreciation | "Splendid", "Marvellous", "Delightful" |
| Affection | "My darling", "Dearest", "My love" |
| Emphasis | "Rather", "Quite", "Exceptionally" |

## Thematic Guidelines

### Approved Themes
- Romantic love and devotion
- Life's beautiful moments
- Gratitude and blessings
- Sophisticated lifestyle
- Optimism and positivity
- Elegant celebration
- Refined ambition

### Theme Treatment

**Romance:** Tasteful, devoted, not crude
```
Good: "Your presence illuminates my world, darling"
Bad: "Girl you bad, lemme get that number"
```

**Success:** Gracious, refined, not boastful
```
Good: "Fortune has smiled upon us rather generously"
Bad: "We getting money, stacking paper all day"
```

**Celebration:** Elegant, sophisticated, not wild
```
Good: "Tonight we raise our glasses to life's splendid moments"
Bad: "Turn up, let's get lit tonight"
```

## Agent Adjustments

When using production agents with this variation:

### BeatDoctor
- Use reggae/island percussion palette
- Warm synths, not trap leads
- Melodic bass, not 808s

### HumanTouch
- Keep refined vocabulary when humanizing
- Natural pauses, not street filler words
- "Rather" and "quite" as fillers, not "like" or "you know"

### VocalCoach
- Melodic ad-libs: "Mmm", "Oh", "Yeah" (sung)
- NO aggressive ad-libs (no "UGH", "BOW")
- Falsetto suggestions for hooks

### CultureCheck
- Verify upper class vocabulary is natural
- Flag any street slang intrusion
- Check for consistent register throughout
