# Open Suno & Prepare

Open Suno.ai in Chrome and prepare for track generation.

## Instructions

1. Open Chrome and navigate to https://suno.com/create
2. Take a screenshot to verify the interface
3. Read the prompt file for Track $ARGUMENTS (or Track 2 if not specified)
4. Display the prompt ready to paste
5. Provide step-by-step instructions for Suno

## Suno Workflow

1. **Mode**: Select "Custom" mode (not Simple)
2. **Lyrics Box**: Paste the lyrics with section markers
3. **Styles Box**: Paste the style tags from the prompt
4. **Create**: Click Create and wait for generation
5. **Review**: Listen to both versions generated
6. **Save**: Download the best version

## Style Tags Format for Suno
```
UK Drill, Aggressive, Dark, 140 BPM, Heavy 808s,
Portuguese hook, Bilingual, Male vocals, Raw delivery
```

After generation, remind user to save audio to `03_audio_exports/`.
