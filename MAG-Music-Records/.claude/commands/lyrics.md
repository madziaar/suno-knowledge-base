# Generate Lyrics

Generate Suno-ready lyrics for Track $ARGUMENTS using the artist style profile.

## Instructions

1. Read `ARTIST_STYLE_PROFILE.md` for signature sound settings
2. Read the corresponding prompt file from `01_prompts/`
3. Read `TRACKLIST.md` for track specs (BPM, mood, type)
4. Generate lyrics with proper section markers: [Intro], [Verse 1], [Chorus], etc.
5. Save to `projects/mixtapes/MAG_Hardcore_Drill_Vol_1/02_lyrics/track_[NN]_lyrics.txt`
6. Update TODO.md

## Language Mix
- Verses: English with London road slang (mandem, ting, wagwan, etc.)
- Chorus: Portuguese (catchy, melodic, repetitive)
- Pre-chorus: Can mix both languages
- Keep hooks simple and memorable

## Section Markers (Suno format)
```
[Intro]
[Verse 1]
[Pre-Chorus]
[Chorus]
[Verse 2]
[Chorus]
[Bridge]
[Outro]
```

Output raw lyrics only with section markers. No explanation.
