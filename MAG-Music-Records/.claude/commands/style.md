# Artist Style Profile

**Command:** `/style` or `/style update`
**Example:** `/style` or `/style update`

---

## Purpose

View or update the MAG Music Records artist style profile and master sound identity.

---

## Workflow

### View Mode (`/style`)
```
1. Read docs/MASTER_STYLE_GUIDE.md
2. Read ARTIST_STYLE_PROFILE.md (if exists)
3. Display formatted summary of current style
```

### Update Mode (`/style update`)
```
1. Ask clarifying questions about changes
2. Update relevant style documents
3. Confirm changes saved
```

## Quick Reference Card

### Always Include in Prompts
- Luxury Trap, Cinematic Hip-Hop
- Deep Commanding Male Vocals
- Heavy 808 Bass
- Grand Orchestral Strings
- Brass elements
- BPM range (74-96)
- "UGH" ad-libs

### Avoid
- BPM over 100
- Aggressive/drill style
- Weak or thin bass
- Fast/choppy flow
- Missing orchestration
