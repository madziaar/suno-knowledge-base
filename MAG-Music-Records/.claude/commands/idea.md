# Add Creative Idea

Add a new idea to SUGGESTIONS.md.

## Instructions

If $ARGUMENTS provided:
- Add the idea to the appropriate section in SUGGESTIONS.md
- Timestamp the entry

If no arguments:
- Ask what type of idea (track concept, marketing, workflow, etc.)
- Prompt for details
- Add to SUGGESTIONS.md

## Idea Categories

1. **Track Ideas** - New song concepts, themes, sounds
2. **Production Notes** - Suno tips, sound design ideas
3. **Marketing Ideas** - Promotion, social media, campaigns
4. **Workflow Improvements** - Automation, templates, tools
5. **Reference Tracks** - Songs to study or draw inspiration from
6. **Ideas Parking Lot** - Quick thoughts for later

## Format

Add ideas in this format:
```markdown
### [Category]
- **[Date]**: [Idea description]
```

After adding, confirm the idea was saved.
