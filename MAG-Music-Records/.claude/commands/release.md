# Release Preparation

Prepare Track $ARGUMENTS (or full album) for distribution.

## Prerequisites Check
- [ ] Prompt exists and approved
- [ ] Lyrics exists and approved
- [ ] Audio generated and exported
- [ ] Description written (under 1000 chars)
- [ ] QC passed (Grade B or higher)

## Release Checklist

### Metadata
- [ ] Track title finalized
- [ ] Artist name correct
- [ ] Featured artists credited
- [ ] Genre tags set
- [ ] Explicit flag set correctly
- [ ] ISRC assigned (if available)

### Assets
- [ ] Audio file: WAV 44.1kHz 24-bit
- [ ] Artwork: 3000x3000px minimum
- [ ] Lyrics synced (optional)

### Distribution
- [ ] DistroKid account ready
- [ ] Release date selected
- [ ] Stores selected
- [ ] Pre-save campaign planned

## Output

Generate a release-ready metadata block and checklist status.

```
=== RELEASE PREP: Track N ===
Status: READY / NOT READY
Blockers: [list if any]
Next Steps: [action items]
```
