## Best Practices

### 1. Prompt Crafting

**Structure Your Prompts:**
```
[Genre/Style] song about [topic] with [mood] featuring [instruments]
```

**Example:**
```
Upbeat indie-pop song about coffee breaks with a cheerful mood featuring acoustic guitar, 
ukulele, and light drums. Include catchy chorus with "Wake up and smell the coffee" lyrics.
```

**Tips:**
- Be specific about genre, not just "music"
- Include 3-5 descriptive adjectives
- Mention desired instruments explicitly
- Specify emotional tone or mood
- Add vocal style preferences (e.g., "breathy", "powerful", "whispery")

### 2. Iterative Refinement

1. **First Draft:** Create basic version to establish direction
2. **Feedback Loop:** Listen critically for areas needing adjustment
3. **Targeted Adjustments:** Modify specific sections (verses, chorus, bridge)
4. **Quality Checks:** Verify mixing levels, vocal clarity, and instrumentation balance
5. **Final Polish:** Apply mastering and export in desired format

### 3. Genre-Specific Approaches

#### Electronic Music
- Specify synth types (wavetable, FM, granular)
- Define bass characteristics (sub-bass depth, punch)
- Include effect chains (reverb decay, delay feedback)

#### Singer-Songwriter
- Emphasize vocal performance and emotion
- Request specific acoustic instrument techniques
- Detail dynamics and dynamic range

#### Hip-Hop/Rap
- Define beat structure and hi-hat patterns
- Specify vocal delivery style (flow, cadence, attitude)
- Include sample references if applicable

#### Orchestral
- List instrumentation sections
- Define arrangement density (sparse vs. dense)
- Specify orchestration style (Baroque, Romantic, Modern)

### 4. Collaboration Workflow

1. **Define Creative Direction:** Establish shared goals and style
2. **Divide Responsibilities:** Assign roles (lyricist, producer, arranger)
3. **Use Versions:** Create labeled versions for comparison
4. **Regular Check-ins:** Review progress and provide feedback
5. **Final Mix:** Coordinate on final mastering decisions

### 5. Rights & Attribution

- Always disclose AI-generated music in credits
- Include "Music generated with Suno v5.5" in metadata
- Verify licensing requirements for your use case
- Consider collaborative credits for human-written lyrics/direction
- Archive original prompts for transparency and reproducibility

## Prompt Engineering Guide

### Prompt Formula Framework

```
[TEMPO] [GENRE] [MOOD/VIBE] song with [KEY INSTRUMENTS] 
[STRUCTURE] [VOCAL STYLE] [UNIQUE ELEMENTS]
```

### Advanced Techniques

#### 1. Descriptor Stacking
```
"Cinematic, orchestral, melancholic, introspective indie-folk ballad with 
sparse arrangement featuring fingerpicked acoustic guitar, strings, and soft vocals"
```

#### 2. Reference-Based Prompting
```
"Similar to [Artist/Song] but with [variation]: 
Electronic, ambient, ethereal synthwave with dreamy vocals and pulsing bassline"
```

#### 3. Emotional Mapping
```
Build emotional arc: 
Intro (mysterious) → Verse (hopeful) → Chorus (explosive) → Bridge (reflective) → Outro (triumphant)
```

#### 4. Technical Specifications
```
BPM: 120 | Key: Am | Time Signature: 4/4
Instrumentation: Lead synth, pad, 808 drums, sidechain compression
Vocal Effect: Slight reverb, 150ms delay, 2-part harmony
```

#### 5. Lyrical Direction
```
"Include chorus that repeats 'Never give up' with powerful delivery"
"Verse about [specific topic] with conversational tone"
"Bridge with key lyric: [specific phrase]"
```

### Common Pitfalls & Solutions

| Problem | Cause | Solution |
|---------|-------|----------|
| Generic output | Too vague prompts | Add 3+ descriptive terms |
| Inaccurate genre | Conflicting style descriptors | Use consistent terminology |
| Poor vocal quality | Unclear vocal direction | Specify vocal performance style |
| Muddy mix | No spatial/EQ guidance | Include "clear mixing" instruction |
| Repetitive structure | No structural guidance | Detail verse/chorus/bridge differences |

## Tips & Tricks

### Pro Tips
1. **Save Successful Prompts:** Create a personal prompt library
2. **Version Control:** Keep track of iterations and improvements
3. **Batch Generate:** Create multiple variations simultaneously
4. **Reference Tracks:** Use listening references for style matching
5. **Collaborate Actively:** Tag feedback directly in the interface
6. **Export Stems:** Use individual tracks for creative remixing
7. **Study Failures:** Learn from unsuccessful attempts
8. **Stay Updated:** Subscribe to feature announcements

- ❌ Vague genre descriptions
- ❌ Conflicting style directions
- ❌ Too many simultaneous requests
- ❌ Ignoring export quality options
- ❌ Forgetting to save project metadata
- ❌ Not backing up important generations
- ❌ Overusing certain effects or instruments
- ❌ Ignoring copyright and usage rights
